## Publish with GitHub Pages

1. Create a new public GitHub repository.
2. Upload every file and folder in this package to the repository root. Keep `index.html` at the root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and the `/ (root)` folder, then save.
6. Wait for GitHub Pages to provide the public URL.

The site is a static HTML5, CSS and JavaScript application. Portrait processing remains local in the visitor's browser.
